# Montage Sourcing Pvt Ltd: Company Website

The official website of **Montage Sourcing Pvt Ltd**, a Noida-based manufacturer and sourcing partner for precision HVAC components.

**Live site:** https://montagesourcing.netlify.app

## About the project

This is a single-page company website built to introduce Montage to international buyers. It covers:

- **Products:** heat exchanger coils, copper assemblies, fans and dampers, sheet metal and ducting
- **Capabilities:** build-to-print manufacturing from customer drawings
- **Quality:** inspection and leak testing before every dispatch
- **FAQ and contact:** enquiry details for buyers

## Design

- Calm, editorial "poster" style: cream paper background, navy text, muted blue and amber accents
- Serif headlines (Fraunces), clean body text (Inter, Archivo) and monospace captions (IBM Plex Mono)
- Real product and factory photos
- Fully responsive layout for desktop and mobile
- Lightweight: plain HTML and CSS with no build step or framework

## Tech stack

| Part | Choice |
|---|---|
| Markup and styling | HTML5, CSS3 |
| Fonts | Google Fonts |
| Hosting | Netlify (static hosting) |
| SEO | `robots.txt`, `sitemap.xml`, meta tags |

## Project structure

```
.
├── index.html      # the full website
├── images/         # product and factory photos
├── robots.txt      # search engine rules
└── sitemap.xml     # sitemap for search engines
```

## Run it locally

No installation needed. Download the repository and open `index.html` in any browser.
